Attention: 디코더가 단어를 생성할 때, 인코더 전체 hidden state 중 필요한 부분을 직접 참조. NMT 성능 향상, Bottleneck problme 해결, 기울기 소실 완화. 해석 가능성, 정렬.
Attention은 각 단어의 표현을 query로 두고, value 집합으로부터 필요한 정보를 직접 불러와 결합함. 
Attention의 Query와 values: decoder의 hidden state와 encoder의 hidden states
1. Query와 values 사이 유사도 점수(score) 계산
2. softmax를 통해 확률 분포
3. 분포를 이용해 values를 가중합 -> context vector


self-attention
attention 메커니즘을 encoder-decoder간이 아닌 한 문장 내부에서 적용. 모든 단어가 각 층에서 직접 상호작용함. 장거리 의존성 포착, 병렬 처리 가능. Query 벡터, Key 벡터, Value 벡터
1. 순서 정보 부재: Positional Encoding(Sinusoidal Position Encoding, Learned Absolute Position Embedding) 
2. 비선형성 부족: Feed-Forward NetWork(Fully Connected + ReLU 등) 추가
3. 미래 참조 문제: Masked Self-Attention


트랜스포머
Self-Attention을 핵심 메커니즘으로 하는 신경망 구조. encoder-decoder 구조로 설계됨. RNN 아님. 병렬 처리 가능. 
Multi-Headed Attention: Attention Head 여러 개
Scaled Dot product: 내적 값을 그대로 사용하지 않고 나눠주어 스케일을 조정함. softmax 함수 출력이 뾰족해져 기울기 소실이 일어나지 않게 함 
Residual Connection: 기울기 소실/폭발을 막기 위해 기존 입력과의 차이만 학습
Layer Normalizaion: 레이어 단위에서 hidden vector 값을 정규화
트랜스포머의 decoder: 단방향 문맥. Masked self-attention(multi-head), Add&Norm(Residual Connection + Layer Normalizaion), Feed-Forward Network(비선형 변환), Add&Norm(Residual Connection + Layer Normalizaion) 4개 구조 
트랜스포머의 Encoder: 양방향 문맥. Decoder와의 차이점은 self-attention에서 masking을 제거한 것 뿐. 
Cross-Attention: Self-attention과는 다르게 Query는 decoder에서, Key와 value는 encoder에서 가져옴. 트랜스포머의 decoder에는 encoder의 출력 표현을 참조하는 cross-attention을 추가하여 입/출력을 연결
