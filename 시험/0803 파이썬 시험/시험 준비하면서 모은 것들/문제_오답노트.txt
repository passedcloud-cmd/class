list.copy()는 얕은 복사(shallow copy)
복사본임에도 중첩된 리스트는 공유가 됨

깊은 복사 쓰는 법
import copy
backup_catalog = copy.deepcopy(catalog)
catalog[3][1] = '내 삶의 변화'
→ backup_catalog만 변함

식별 연산자(is)로 backup_catalog와 catalog 비교
print(catalog is backup_catalog)          # False (서로 다른 객체)
print(catalog[3] is backup_catalog[3])    # False (깊은 복사라 안쪽 리스트도 별개)
print(catalog[3][1] == backup_catalog[3][1])  # 값 비교: 다름 (수정됐으므로)

시험 대비 02_함수 practice 1: 1번 all() 구현 / 2번 any() 구현

`all()`은 인자로 받는 iterable(range, list)의 모든 요소가 참이거나 비어있으면 True를 반환합니다. 
my_all([]) #=> True
my_all([1, 2, 5, '6']) #=> True
my_all([[], 2, 5, '6']) #=> False

`any()`는 인자로 받는 iterable(range, list)의 요소 중 하나라도 참이면 True를 반환하고, 비어있으면 False를 반환합니다. 
my_any([1, 2, 5, '6']) #=> True
my_any([[], 2, 5, '6']) #=> True
my_any([0]) #=> False

파이썬에서 False로 취급되는 것들, 나머지는 전부 True
bool(0)        # False
bool(0.0)      # False
bool("")       # False
bool([])       # False (빈 리스트)
bool(())       # False (빈 튜플)
bool({})       # False (빈 딕셔너리)
bool(set())    # False (빈 집합)
bool(None)     # False

if 27:	27  |  27이 참으로 평가되는가  |   True
bool(27) == True    |  bool(27)의 값이 True와 같은가  |	True
bool(27) is True   |  bool(27)이 진짜 True 객체인가  |	True (싱글턴이라서)
27 is True	|  27이 True와 동일한 객체인가  |    False

def is_pal_recursive(word):
    if len(word) <= 1:
        result = True
        return result
    if word[0] == word[-1]:
        word = word[1:-1]
        return is_pal_recursive(word)
    else:
        result = False
    return result

min 함수
min(iterable, *[, key, default])
min(arg1, arg2, *args, *[, key])
빈 시퀀스를 처리할 때 에러가 나옴. 에러를 방지하기 위한 default 값 설정 가능

print(min(words, key=len))  # 가장 짧은 단어 출력: 'date'

scores = {'math': 80, 'english': 95, 'science': 75}
lowest_subject = min(scores, key=lambda k: scores[k])
print(lowest_subject)  # 출력: 'science'

empty_list = []
print(min(empty_list, default="리스트가 비어있습니다."))

sort와 sorted
list.sort(): 원본 리스트를 직접 변경하며, 반환값은 None입니다. 원본 자체를 변경. 리스트 객체에서만 사용할 수 있습니다.
내림차순: list.sort(reverse=True)
조건 지정 (key): 글자 길이 등 특정 조건을 기준으로 정렬할 때 사용합니다 (예: list.sort(key=len))

sorted(iterable): 원본을 유지하고 정렬된 새로운 리스트를 반환합니다. 리스트 외에도 튜플, 문자열 등 다양한 객체에 사용할 수 있습니다.
내림차순: sorted(list, reverse=True)
