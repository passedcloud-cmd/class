### 비시퀀스 데이터 구조

(이미지 표)

비시퀀스의 장점: 인덱스가 사라짐.
시퀀스에서 인덱스로 데이터를 찾으려면 처음부터 하나씩 대조해야 하지만, 비시퀀스는 이름표를 곧바로 위치로 바꿔서 한 번에 찾음. 속도 빠름

#### 딕셔너리

키와 값을 짝지어 저장하는 자료구조
내부적으로 해시 테이블을 사용하여 키-값 쌍 관리
데이터의 크기와 관계 없이 매우 빠름
키는 hashable한 고유값. 값은 중복이 가능하고 어떤 자료형도 저장 가능.

#### 딕셔너리 메서드

.get(key[,default])
키에 연결된 값을 반환.
키가 없으면 None 혹은 기본값(선택 인자)을 반환

.keys()
딕셔너리 키를 모은 객체를 반환
person = {'name' : 'Alice', 'age' : 25}
print(person.keys()) # dict_keys(['name', 'age']) ← 리스트 형태. 반복이 가능한 값임!
for item in person.keys():
	print(item)
"""
name
age
"""

.values()
딕셔너리 값을 모은 객체를 반환

.items()
딕셔너리 키/값 쌍을 모은 객체를 반환
튜플 형태로 반환. 

.setdefault(key[, default])
키와 연결된 값을 반환
키가 없다면 default(값)와 연결한 키를 딕셔너리에 추가하고 default(값)를 반환

person.setdefault('country', 'KOREA') 했을 때 country 키가 없으면 'Country' : 'KOREA' 쌍을 추가

.update([other])
* ohter는 딕셔너리에 추가하거나 갱신할 키-값 쌍을 가진 다른 데이터 객체를 의미하는 자리 표시자
other가 제공하는 키/값 쌍으로 딕셔너리를 갱신하고 기존 키는 덮어씀

.pop(key[, default])
키를 제거하고 연결됐던 값을 반환
키가 없으면 에러나 default를 반환함

.clear()
딕셔너리의 모든 키/값 쌍을 제거

### 딕셔너리의 확장: defaultdict
파이썬 내장 모듈 collections에서 제공하는 딕셔너리의 확장판
딕셔너리에 존재하지 않는 키를 조회할 때, 자동으로 '기본값'을 생성해주는 자료구조
KeyError 걱정 없이 값을 수정하거나 추가할 때 매우 유용함
import collections를 해야 함
collections 모듈: 파이썬의 범용 내장 컨테이너를 대체하거나 보완하기 위해, 더 효율적이고 특수한 기능을 갖춘 고성능 컨테이너 데이터 타입을 제공하는 표준 라이브러리

예시) 색깔별 과일 분류하기
color 키가 없으면 'red' : [] 라는 빈 리스트를 생성하고 바로 딕셔너리에 append 해줌. 

주의사항
defaultdict는 조회만 해도 키가 생성됨
단순히 키가 있는지 확인할 때는 주의해서 사용할 것

### SET
교유한 항목들의 정렬되지 않은 컬렉션
내부적으로 해시 테이블을 사용하여 데이터를 저장
항목의 고유성을 효율적으로 보장
항목의 추가, 삭제, 존재 여부 확인이 데이터의 크기에 관계 없이 매우 빠름
합집합, 교집합, 차집합 등 수학적인 집한 연산을 간편하게 수행할 수 있음

#### 세트 매서드
.add(x)
세트에 x를 추가

.update(iterable)
세트에 다른 iterable 요소를 추가

.clear()
세트의 모든 항목을 제거

.remove(x)
세트에서 항목 x를 제거, 항목 x가 없을 경우 keyError ← 딕셔너리와 구조가 같음

.pop()
세트에서 임의의 요소를 제거하고 반환

.discard(x)
세트 s에서 항목 x를 제거. remove와 달리 에러 없음.

### 해시 테이블
키와 값을 짝지어 저장하는 자료구조
키를 해시 함수를 통해 해시 값으로 변환함

John Smith라는 key를 넣었을 때 항상 반드시 02라는 해시 값이 나와야 함. 
key가 hash function을 거치면 항상 같은 해시 값을 변환함.
그 해시 값을 인덱스로 삼아 데이터를 저장하거나 찾음.

(이미지)

해시
임의의 크기를 가진 데이터를 고정된 크기의 **고유한 값**으로 변환하는 것
생성된 해시 값(고유한 정수)은 해당 데이터를 식별하는 '지문'역할

해시 함수
임의 길이 데이터를 입력 받아 고정 길이(정수)로 변환해 주는 함수. 이 정수가 바로 해시 값

set의 요소 & dict의 키와 해시 테이블 관계
set
각 요소를 해시 함수로 변환해 나온 해시 값에 맞춰서 해시 테이블 내부 버킷에 위치시킴
순서가 아니라 버킷 위치(인덱스)가 요소의 위치를 결정
set를 print할 때 마다 순서가 바뀐 이유는 버킷의 위치가 바뀌기 때문 ← 해시 함수에서 나온 해시 값이 매번 변하기 때문
우리가 보는 건 버킷의 위치일 뿐. 버킷에 위치된 데이터를 보는 것.

set의 pop 메서드 예시
임의의 값을 pop한다 ← 해시 함수를 거칠 때마다 해시 값이 달라지기 때문. 하지만 파이썬을 동일 프로세스에서 연속 실행할 때는 시드 값이 같아서 같을 것. 그때까진 버킷의 위치가 같으니까. 새로운 환경으로 변해야 시드 값이 변해서 버킷의 위치가 변함

set의 pop 메서드 예시 - 정수
정수 데이터 → 해시 함수 → 고정된 정수
(의도된 게으름) 정수를 넣으면 해시 값이 숫자 자기 신과 동일하거나 단순 계산으로 고정됨

set의 pop 메서드 예시 - 문자열
문자 데이터 → 해시 함수 → 고정된 정수
문자열은 해시 계산 시 파이썬의 해시 난수화가 적용되어, 실행마다 순서가 달라짐

해시 난수화와 난수 시드
파이썬 프로세스가 새로 시작될 때마다 해시를 계산할 때 사용하는 난수 시드가 달라짐
해시 함수가 매번 바뀌는 것이 아니라, 해시 계산에 쓰이는 시드 값이 실행마다 달라지는 것
이로 인해 동일한 데이터라도 매번 해시 값이 달라져 결과적으로 버킷 배치가 달라짐

pop이 될 때 임의는 랜덤이라는 의미는 아님. 임의라는 의미에서 무작위라고 함

hashable
hash() 함수에 넣어 해시 값을 구할 수 있는 객체를 의미
데이터의 불변 타입은 해시 가능
가변형 객체는 기본적으로 해시 불가능
해시 테이블(예: set, dict의 KEY)에는 hashable(해시가 가능한 객체)만 저장 가능
불변 객체는 생성 후 값 변경이 불가능하므로 항상 같은 해시 값을 유지 → 해시 테이블이 안정적으로 동작
"hash가 가능하다 == 불변이다"는 절대적이지는 않지만 일반적으로 내장 자료형 기준에서는 불변이어야 함

가변형 객체가 hashable하지 않은 이유
값이 변경될 수 있으므로 같은 객체라도 값이 바뀌면 해시 값도 달라질 수 있음
예) 리스트, 집합, 딕셔너리 자체를 set이나 dict의 키로 쓸 수 없음
