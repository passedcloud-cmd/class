정형적인 데이터는 고전적 머신러닝이 더 우수할 수 있음
이미지, 음성, 영상 같은 데이터는 딥러닝이 더 우수

퍼셉트론 구성요소
b는 기준선을 자유롭게 이동할 수 있는 수치

가중치w와 편향b를 바꾸면서 y를 수정
y= wx + b

XOR의 경우 층을 여러 개 쌓아야 해결 가능
퍼셉트론을 여러 층으로 쌓기
입력층: 데이터가 들어오는 곳
은닉층(1개 이상 존재): 데이터의 핵심 특징을 추출하고 학습하는 부분
출력층: 최종 예측 결과를 내보내는 곳

Flatten 현상
8x8 이미지 입력 → 선형데이터 - 일렬로 받아냄. Flatten → [0, 5, 8, 9, ...] 64개의 한 줄.
문제점: Flatten되면 픽셀의 위치 데이터를 잃어버림
그래서 이미지 처리에 약합

은닉층이 직선으로 나눌 수 있게 공간을 바꿔놓음
은닉층이 깊어진다 - 여러 번 접는다 - 복잡한 모양도 나눌 수 있다

활성화 함수
비선형성을 추가. 복잡한 패턴을 학습할 수 있게 해주는 스위치 역할
시그모이드(과거) 함수
ReLU(현재): 입력이 0보다 작으면 0을 출력. 0보다 크면 값을 그대로 출력.

시그모이드 함수는 S자 곡선
기울기 최대가 0.25
퍼셉트론 층을 10번 거치면 가중합 0.25를 10번 곱하게 됨
사실상 0에 수렴하게 됨
퍼셉트론이 가중합을 구하는 이유는 다음 신호로 이렇게 말하는 것
"가중치를 이렇게 고쳐"
하지만 퍼셉트론 층을 거칠수록 이 신호가 작아짐.
앞쪽 층가지 가지 못하고 사라짐. 깊은 신경망 모델을 만들 수 없음

지금 활용하는 ReLU 함수는 규칙이 매우 단순
0보다 크면 그 값 그대로, 0보다 작으면 0
기울기가 1 아니면 0임
아무리 곱해도 신호가 사라지지 않음

MLP의 학습과정
1. 순전파
2. 손실 함수 계산
3. 역전파
4. 옵티마이저

1단계 순전파
순전파의 방향은 입력층 - 은닉층 - 출력층
초기에는 무작위 가중치로 시작
0부터 시작하면 다양성이 떨어짐. 모두 똑같은 결과를 내게 하니까.
서로 다른 특징을 갖도록 무작위 가중치를 갖게 함
처음엔 엉터리 결과가 나옴

2단계 손실 함수(모델의 오답 노트)
얼마나 틀렸는지 하나의 숫자로 계산
손실값을 줄이는 게 목표
회귀면 평균 제곱 오차(얼마나 멀리 빗나갔나)
분류면 교차 엔트로피(정답에 얼마나 확신했나)
확신을 갖고 틀리면 벌점을 아주 크게 줌. 할루시네이션과 관련된 사항

3단계 역전파
손실의 원인을 찾아 추적함
책임을 뒤쪽 층에서 앞쪽 층으로 전달
가중치는 자신의 책임량에 비례하여 손실을 줄이는 방향으로 계산

4단계 옵티마이저
역전파로 계산된 책임(가중치 기울기)을 바탕으로 최적의 가중치를 찾아감
Adam이라는 옵티마이저를 가장 많이 썼는데
Adam도 계손 버전이 업데이트 되나 봄
관성: 학습 방향을 유지

PyTorch 코드 연계

과적합: 모델이 훈련 데이터만 너무 열심히 외워서, 처음 보는 데이터에 응용력이 떨어짐

규제: 과적합을 막기 위해 모델에 제약을 거는 기법

드롭아웃: 은닉층의 뉴련을 일정 확률로 랜덤하게 OFF
다양성 증가
특정 뉴런에 지나치게 의존하는 것을 방지
경우의 수가 변했기 때문에 새로운 결과가 나옴
앙상블 효과

훈련 종료 시점 정하기
학습 루프
조기 종료: 과적합이 오기 전, 가장 결과가 좋았을 때 훈련을 멈춤

옵티마이저 Adam
경사하강법: 가장 기본적인 옵티마이저
학습률이 높은 경우: 손실 함수 값이 줄어들지 않고 오히려 커지는 오버슈팅
학습률이 낮은 경우: 지역 최저점에 빠질 수 있음

Adam(Adaptive Moment Estimation)
1. 관성 도입(가던 방향으로 가는 흰색 공)
오차가 줄어드는 것 같으면 학습 방향에 속도를 냄
오류를 내는 것 같으면 빠져나감
적응적 합습률을 도입했기 때문에 가능
2. 적응적 학습률
많이 움직였던 가중치에 대해서는 학습률을 작게 만들어서, 적게 움직이도록 함
적게 움직였던 가주이에 대해서는 학습률을 크게 만들어서, 빠르게 학습을 진행
