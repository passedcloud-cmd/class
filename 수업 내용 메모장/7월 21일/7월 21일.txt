인자(argument)
*함수를 호출할 때* 실제로 전달하는 값



인자 종류 5가지
1. positional arguments(위치 인자)
함수 호출 시 인자의 위치에 따라 전달되는 인자
입력하는 인자의 위치를 확인해야 함.
위치 인자는 함수 호출 시 반드시 값을 전달해야 함.
def greet(name, age):
	print(f'안녕하세요, {name}님! {age}살이시군요.')

2. Default argument values(기본 인자 값)
함수 정의에서 매개변수에 기본 값을 할당하는 것
함수 호출 시 인자를 전달하지 않으면. 기본값이 매개변수에 할당됨
def greet(name, age=30):
	print(f'안녕하세요, {name}님! {age}살이시군요.')

→ age 인자를 입력하지 않으면 age=30이라고 나옴

3. Keyword Arguments(키워드 인자)
함수 호출 시 인자의 이름과 함께 값을 전달하는 인자
매개변수와 인자를 일치시키지 않고 특정 매개변수에 값을 할당할 수 있음
인자의 이름을 명시하니까 순서는 중요하지 않음. 
단! 호출 시 키워드 인자는 위치 인자 뒤에 있어야 함.
인자를 입력할 때 위치 인자가 앞에 올 것.
def greet(name, age):
	print(f'안녕하세요, {name}님! {age}살이시군요.')

greet(age=35, name='Dave')
greet(age=35, 'Dave') 

왜 위치 인자가 앞에 있어야 할까?
→ 순서의 모호성 때문.
이미 키워드 인자로 순서가 깨진 상태에서 다시 위치 인자를 전달하면 컴퓨터는 이 값이 몇 번째에 들어가야 하는지 모름

4. Arbitrary Arguments(임의의 인자 목록)
가변 인자
정해지지 않은 개수의 인자를 처리하는 인자
함수 정의 시 매개변수 앞에 *를 붙이면 여러 개의 인자를 tuple로 처리함
def calculate_sum(*args):

재귀 함수
함수 내부에서 자기 자신을 호출하는 함수
예시)
팩토리얼. n! = n * (n-1)! = n * (n-1) * (n-2)
자기 자신을 재귀적으로 호출하여 입력된 숫자 n의 팩토리얼을 계산
n이 0이 될 때까지 반복, 종료 조건을 설정하여 재귀 호출이 멈추도록 함
종료조건을 확인해야 함 
def factorial(n):
	# 종료 조건은 n이 0이면 1을 반환
	if n == 0
		return 1
	else:
		# 재귀 호출: n과 n-1의 팩토리얼을 곱한 결과를 반환
		return n * factorial(n-1)
print(factorial(5))	120

팩토리얼 5를 호출 → 내부에서 팩토리얼 4를 호출 → 팩토리얼 3을 호출 → 1을 반환활 때까지 반복.
base case(종료되는 상황)에 수렴.
홀스텍에 호출이 쌓임.
호출을 최근 것부터 하나씩 꺼내면서 연산

재귀 함수 특징
특정 알고리즘 식을 표현할 때 변수의 사용이 줄어들어 코드의 가독성이 높아짐. 간결함.
1개 이상의  base case(종료되는 상황)가 존재하고 수렴하도록 작성

주의
종료 조건을 명확히 해야 함. 반복되는 호출이 종료 조건을 향하도록 짤 것.
스택 오버플로우 : 작업 공간에 일이 너무 많이 쌓여 프로그램이 멈추는 오류. 홀스텍이 넘침.

python의 범위(scope)
함수는 코드 내부에 local scope를 생성. 그 외의 공간은 global scope로 구분.
global scope : 코드 어디에서든 참조할 수 있는 공간.
local scope : 함수가 만든 scope(함수 내부에서만 참조 가능)
global variable : global scope에 정의된 변수
local variable : local scope에 정의된 변수
예시)
def func( ):
	num = 20
	print('local', num) # local 20
func( )
print('global', num) # NameError: name 'num' is not defined

num은 local scope에 존재하기 때문에 global scope에서 사용할 수 없음.
num은 함수가 끝남과 동시에 사라짐

변수의 수명 주기(lifecycle)
변수가 선언되는 위치와 scope에 따라 결정됨
1. built-in scope : 파이썬이 실행된 이후부터 영원히 유지
2. globacl scope : 모듈이 호출된 시점 이후 혹은 인터프리터가 끝날 때까지 유지
3. local scope : 함수가 호출될 때 생성되고, 함수가 종류될 때까지 유지

이름 검색규칙 (Name Resolution, LEGB rule)
파이썬에서 사용되는 이름(식별자)들은 특정한 이름 공간에 저장되어 있음.
1. Local scope: 지역 범위(현재 작업 중인 범위)
2. Enclosed scope: 지역 범위 한 단계 위 범위
3. Global scope: 최상단에 위치한 범위
4. Built-in scope: 모든 것을 담고 있는 범위(정의하지 않고 사용할 수 있는 모든 것)
