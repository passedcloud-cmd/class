### 학원 가서 클론으로 받으면 ###
1) cd 프로젝트폴더
2) npm install
(꼭 프로젝트 폴더와 같은 위치일 때 node_modules 폴더 생성됨. node_modules 폴더는 용량이 커서 보통 git에 올리지 않아요 (.gitignore에 포함되어 있을 거예요). )그래서 git clone으로 받은 폴더에는 node_modules가 없는 게 정상이고, npm install로 그 컴퓨터에서 새로 설치해줘야 합니다.
3) # .env 파일 직접 생성 (VSCode에서)
챗봇 API키 받아야 함
4) npm run dev

.env 파일은 git에 안 올라가 있다는 점 기억하기
.env 파일(API 키)은 의도적으로 git에서 제외했었죠. 폴더를 삭제하면 .env 파일도 같이 사라지고, 이건 클론으로 절대 복구가 안 돼요. 삭제 전에 .env 파일 내용(API 키)을 어딘가에 따로 메모해두세요.
