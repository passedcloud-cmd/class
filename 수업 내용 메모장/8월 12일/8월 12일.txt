## 환경 설정 및 핵심 라이브러리

### 환경 변수
전역 설정값
프로그램은 이 변수를 통해 API키, DB 비밀번호 등을 코드 외부에서 읽음
API키처럼 민감한 정보를 환경 변수에 관리
개발/테스트/배포 환경마다 다른 API키를 사용할 때, 코드를 수정하지 않고 환경 변수 값만 변경하면 됨
GitHub에 API키가 올라가면 커밋에 기록이 남기 때문에, 키가 유출되면 지우려하기 보다 발급처에서 키를 즉시 폐기하고 새로 발급받기

https://gms.ssafy.io/web/ 사이트에서 API 키를 복사
같은 경로 폴더에 .env 파일을 생성 후 GMS_KEY="여기에_복사한_API키를_붙여넣기" 작성
.env 파일은 키=값 형태로 환경 변수를 저장하는 텍스트 파일
.gitignore에 .env를 추가하여 github에 올리는 것을 방지

팀원들과 파일을 공유할 땐 .env.example 파일을 생성 후 GMS_KEY="" 작성
팀원은 이 파일을 복사해 .env로 이름을 바꾸고 자기 키를 채워 넣음

 response API는 둘 다 지원하나
Responses API를 권장함. 최선 버전
왼쪽 chat completions API는 옛날 버전. 
gpt에게 입력할 때 response API로 작성해달라고 해야 할 것

자주 발생하는 오류
| 증상 | 원인 | 해결 |
|---|---|---|
| `GMS_KEY가 설정되지 않았습니다` | `.env`가 다른 폴더에 있음 | 노트북과 **같은 폴더**로 이동 |
| 같은 증상 | 파일명이 `.env.txt` | 윈도우에서 확장자 표시를 켜고 이름 수정 |
| 같은 증상 | 키 이름 오타 (`GMS_API_KEY` 등) | 정확히 `GMS_KEY` |
| 같은 증상 | `.env`를 고친 뒤 그대로 실행 | 커널 재시작 후 처음부터 재실행 |

커널: 코딩을 실행하고 결과를 보여주는 독립된 백그라운드 연산 엔진
`load_dotenv()`는 셀을 실행하는 시점에 파일을 읽으므로, 파일을 수정했다면 그 셀을 다시 실행해야 반영된다.
