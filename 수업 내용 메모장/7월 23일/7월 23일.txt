데이터 구조
여러 데이터를 효과적으로 사용 관리하기 위한 구조(str, list, dict 등)

자료 구조
각 데이터의 효율적인 저장, 관리를 위한 구조를 나눠 놓은 것

## 메서드

객체에 속한 *함수*. 사용하려면 호출을 해야 함
문자열, 리스트, 딕셔너리 등 파이썬의 다양한 데이터 구조는 저마다 고유한 메서드를 가짐
(문자열, 리스트, 딕셔너리는 객체)

메서드는 클래스 내부에 정의되는 함수

메서드 호출 방법
우리가 만든 객체(데이터)에게 원하는 명령(메서드)을 내리는 방법
데이터 타입 객체.메서드()
문자열 예시)
'hello'.capitalize()
print('hello'.capitalize()) # Hello
'hello' 문자열은 불가변이라서 원본이 바뀐 건 아님. 
'hello'.capitalize()가 새로운 문자열을 반환(return)한 것

리스트 메서드 예시)
numbers = [1, 2, 3]
numbers.append(4)
print(numbers) # [1, 2, 3, 4]
append는 반환값이 없음. ← int(numbers.append(4)) # None


### 공통 시퀀스 메서드

.index(x)
시퀀스에서 첫 뻔재로 일치하는 항목 x를 반환. x가 없으면 ValueError

.count(x)
시퀀스에서 항목 x의 개수를 반환

### 불변 시퀀스 메서드(문자열 전용)

#### 탐색 및 검증

.find(x)
x의 첫 번째 위치를 반환. 없으면 -1을 반환. x의 위치를 알아야 할 경우에 사용
.isupper()
문자열 내 모든 문자가 대문자인지 확인
.islower()
문자열 내 모든 문자가 소문자인지 확인
.isalpha()
문자열이 비어있지 않고, 무든 글자가 문자(유니코드 상 letter)일 때만 True 반환

#### 문자열 조작 매서드(새로운 문자열 반환. 문자열은 불변이기 때문에)
꼭 외워야 하는 매서드
str.replace
str.strip
str.split
str.join

.replace(old, new[, count])
괄호 [, count]는 선택인자라는 뜻
기존 문자열에서 "old"라는 부분 문자열이 "new"로 모두 바뀐 문자열을 반환
선택인자에 1을 적으면 맨 앞에 있는 1번만 바꿈

.strip([chars])
선행과 후행 문자가 제거된 문자열의 복사본을 돌려줌
문자열 중간의 공백은 제거되지 않음.
아무것도 지정하지 않으면 공백(띄어쓰기, 탭, 엔터)을 제거
문자열 집합으로 제거(순서 상관 없음)

.split(sep=None, maxsplit=-1)
기본 인자가 2개
sep를 구분자 문자열로 사용하여 문자열에 있는 단어들의 리스트를 반환
maxsplit이 주어지면 최대 maxspit번 분할을 수행

join(iterable)
iterable 문자열을 연결한 문자열을 반환
생긴 게 조금 특이함

가변 시퀀스 메서드(리스트 전용)
L. append(x)
L.extend(iterable)
L.pop()
L.pop(i)

L. append(x)
리스트 마지막에 항목 x를 추가
반환값은 없음

L.extend(iterable)
리스트에 다른 반복 가능한 객체의 모든 항목을 추가
특이하게 여러 개의 요소를 하나씩 넣을 수 있음

append()와 extend()의 비교
my_list.append([5, 6, 7])
print(my_list) #[1, 2, 3, 4, 5, 6, [5, 6, 7]]
  
my_list.extend(100)
# TypleError. 반복 가능한 객체가 아니면 추가 불가함

.insert(i, x)
x를 지정한 인덱스 i 위치에 삽입

.remoe(x)
리스트에서 첫 번째로 일치하는 항목을 삭제

L.pop() 또는 L.pop(i)
리스트에서 지정한 인덱스의 항목을 제거하고 *반환* ←변수에 담아서 활용 가능
작성하지 않을 경우 마지막 항목을 제거
i를 입력하면 i번째 요소를 반환
값을 삽입하고 제거할 때 .pop과 .append 많이 쓰임
(append는 반환값이 없음)

.clear()
리스트의 모든 항목을 제거
리스트는 그대로 두지만 안에 있는 요소만 초기화

정렬 및 순서 변경
.reverse()
리스트의 순서를 역순으로 변경. 정렬X
반환 없음

.sort()
원본 리스트를 오름차순으로 정렬
반환 없음
reverse=True를 넣으면 내림차순 정렬


복사
가변/불변 객체의 개념

Mutable(가변) 객체

Immutable(불변) 객체


변수 할당의 의미: 파이썬에서 변수 할당은 객체에 대한 참조를 생성하는 과정
변수는 객체의 메모리 주소를 가리키는 Label 역할을 함

가변 객체 예시: 생성 후 내용을 변경할 수 있는 객체

불변 객체 예시: 생성 후 내용을 변경할 수 없는 객체
id() 함수를 상요하여 메모리 주소 확인
is 연산자로 확인 가능

가변/불변 메모리 관리 방식

얕은 복사
객체의 최상위 요소만 새로운 메모리에 복사
[1, 2, 3 [100, 3]] 에서 1, 2, 3만 새로운 메모리 복사. [100, 3]은 참조만 복사됨

리스트 슬라이싱, copy 매서드, list 함수
원본 리스트와 동일한 새로운 리스트를 만듦. 새로운 메모리 주소가 생김

얕은 복사의 한계
2차원 리스트처럼 리스트 안에 중복된 리스트가 있으면, 안에 있는 리스트의 주소는 같음
복사가 덜 된 것. 하위부터는 복사가 안 된 것. 

깊은 복사
객체의 모든 수준의 요소를 새로운 메모리에 복사
중첩된 객체까지 모두 새로운 객체로 생성됨
copy 모듈에서 제공하는 deepcopy() 함수를 사용해야 함
import copy

new_object = copy.deepcopy(original_object)

1차원 리스트는 얕은 복사로 해도 됨

메서드 체이닝 주의사항
모든 메서드가 체이닝을 지원하는 건 아님: 메서드가 객체를 봔환해야 체이닝 가능
None을 반환하는 메서드는 메서드 체이닝 불가능
my_list = [1, 2, 3]
print(my_list.append(100).pop())
AttributeError: 'NoneType' object has no attribute 'pop'
# my_list.append(100)은 None이기 때문에 None.pop은 안됨 

앞에 있는 게 반환값이 없으면 메서드를 이을 수 없음
뒤에 있는 게 반환값이 없으면 변수에 할당할 수 없음
메서드 체이닝을 포기하고 둘을 각각 따로 적는 식으로 해야 함
