2. Sequence Types 여러 개의 값들을 순서대로 나열하여 저장하는 자료형
시퀀스: 여러 데이터가 정해진 *순서*대로 일렬로 *나열*한 자료 구조 
모든 칸에는 0번부터 시작하는 고유한 번호(인덱스)가 있음
시퀀스 타입의 5가지 공통 특징
1) 순서(order)
정렬 아님
2) 인덱싱(indexing)
특정 위치의 값을 선택하거나 수정할 수 있음
3) 슬라이싱(slicing)
전체 데이터 중 원하는 부분만 값을 잘라내서 사용 가능
4) 길이(length)
값의 개수(길이)를 구할 수 있음
5) 반복(iteration)
반복문으로 각 값을 하나씩 순서대로 꺼내서 사용 가능

리스트
모든 종류의 데이터를 담을 수 있음
리스트는 시퀀스이므로 문자열처럼 인덱싱, 슬라이싱, 길이 확인, 반복 등 공통 기능 모두 사용 가능
중첩 리스트(Nested list)
다른 리스트를 값으로 가진 리스트
중첩 리스트에 접근하기: 인덱싱 [ ]를 연달아서 적으면 됨
리스트는 변경 가능한(mutable) 시퀀스 자료형
1) 인덱싱으로 값 수정하기 : my_list[1] = "two"   (1번째를 two로 바꾸기)
2) 슬라이싱으로 여러 값 한번에 바꾸기 my_list[2:4] = ['three', 'four']   (2번째와 3번째를 각각 바꾸기)

튜플
변경 불가능한 시퀀스
단일 요소 튜플을 만들 때는 반드시 Trailing comma(후행 쉽표)를 적어야 함.
예시 my_tuple_2 = (1, )
튜플은 개발자가 잘 선언하는 건 아님.
내부 동작에 많이 씀. 파이썬이 내보낸 정보에 튜플이 있을 수 있음.
언패킹 가능

range
연속된 정수 시퀀스를 생성
변경 불가능한 자료형
반복문과 함께 사용, 코드를 반복 실행할 때 유용함
range(start, stop, step)
매개변수를 가질 수 있음
my_range_! = range(5)
print(my_range_1) # range(0, 5)가 나옴
메모리를 효율적으로 사용하기 위해 활용할 때 값이 나옴.
range(list(my_range_1)) # [0, 1, 2, 3, 4]

딕셔너리 dict
key - value 쌍으로 이루어짐
순서와 중복이 없음. 변경 가능한 자료형
순서가 없다 → 시퀀스가 아님. 
key: 값을 식별하기 위한 고유한 이름표. 중복 불가.
	변경 불가능한(immutable) 자료형만 사용 가능.
	str, int, float, tuple은 가능. list, dict는 불가능
value: 키에 해당하는 실제 데이터. 어떤 자료형이든 자유롭게 사용 가능.
각 값에는 순서가 없음 → 인덱스가 없음. key를 통해 접근해야 함.

print(my_dict['name') # '홍길동'
# key-value 쌍 추가
my_dict['banana'] = 50 # 'banana' : 50 을 추가
# 변경
my_dict['apple'] = 100 # 'apple' : 100으로 값 변경
